2. Copie o index.html deste pacote para a raiz do projeto, substituindo o anterior.

4. Mantenha todos os demais arquivos do projeto. Este pacote é uma atualização, não o projeto completo.
5. Abra pelo Live Server no VS Code e atualize com Ctrl+F5.
